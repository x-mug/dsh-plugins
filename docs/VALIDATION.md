# 1.1.0 验证记录

验证日期：2026-10-29。兼容基线：DSH Desktop 0.2.1-rc.3、Cordis 4.0.5、Windows 11、Node.js 24.18.0。

## 自动化

- 文件链接插件 58 项通过，包含实际 DSH 文件地址解析和 Cordis 注册/卸载集成；源码和既有 1.1.0 安装包未改。
- 会话查找插件 208 项通过，零失败、零跳过。覆盖真实 Worker 的取消与正则超时恢复、历史水位与连续分页证明、授权/预算/归档变化、UTF-16 来源与 Range 核对、异步导航隔离、跨会话交接和 UI 生命周期。
- 使用实际 rc.3 ShortcutRegistry 在 Desktop/Web × macOS/Windows/Linux 六种配置下验证注册。服务命令默认未绑定，直接 Ctrl/Cmd+F 由限定作用域的 DOM 监听处理。
- UI 优先级回归复现了旧版重复消费引发的 React 更新循环；新版本在外部 store 更新前同步消费交接引用，避免重复导航。
- 新侧栏尚未建立 surface 时，仅对明确的暂未就绪错误在既有 20 秒交接期限内等待；测试覆盖取消、超时、第三会话打断、卸载和同步通知重入。
- 构建脚本与内存重算构建检查一致。安装包逐文件比对源码，并提供 SHA256 校验值。

## 真实运行页面

使用现有 DSH host 的正常认证入口，在独立 Chrome context 中运行，不创建新消息，不把查询正文、会话 ID 或凭据写入报告。

已验证：

1. 插件激活，模块和快捷键注册无冲突。
2. Ctrl+F 打开面板、阻止浏览器默认事件并聚焦输入；标题栏按钮可以打开面板。
3. 当前会话独立读取历史，完成覆盖核对后给出结果。
4. 点击用户文本命中，Range 与原文查询一致，消息行和会话归属一致，范围可见。
5. 所有会话扫描结束，结果标明覆盖状态。
6. 全局结果命中当前会话时正确交接并精确高亮。
7. 点击来自另一会话的命中，目标会话挂载，面板归属目标，Range 文字、目标会话和消息行均一致。
8. Escape 关闭面板并清除插件高亮。上述导航无 console error、slot error 或未捕获异常。

Desktop 原生 Electron 按键路径未进行操作系统输入级自动化。若原生层先于 DOM 接管按键，可使用标题栏按钮、命令面板或自定义绑定。

## 红队发现与修复

独立红队使用 linus-review，重点审查数据流、控制流与兼容破坏面。源码探针和真实页面共同暴露并修复：

- 缺页仍宣称完整、临时窗口覆盖权威内容。
- Markdown 相同文字按 occurrence 猜位置造成错误精确高亮。
- Ctrl+F 缺少 Web 路径，以及默认备用键跨平台与宿主命令冲突。
- 迟到的交接覆盖新查询、关闭后局部 Worker 仍保留。
- 异步 React state 清消费标记遇外部 store 同步更新导致 #185。
- 目标会话已选择而侧栏 surface 尚未建立时过早调用 openTab。

测试桩曾漏掉真实快捷键冲突和 React 提交优先级问题；对应宿主实现与优先级反证现已加入回归。通过自动化不单独构成真实 GUI 成功证据。

## 保留边界

- 正文与 Markdown 渲染全文无法完全核对时，降级为消息定位并提示，避免误报精确高亮。
- 全局扫描固定每个会话的独立水位，不是所有会话的原子快照。归档搜索可选，打开前须由用户取消归档。
- 客户端扫描限额和 Worker watchdog 不构成宿主 CPU、内存或 I/O 硬上限。rc.3 的冷 projections/page 可能准备或折叠整份日志；已开始的宿主工作不一定随客户端取消立即终止。
- 性能表属于合成语料的引擎/Worker 记录；本轮 GUI 通过不等于端到端延迟或峰值内存测量。
